# Feature Specifications

One folder per feature: FEAT-XXX-short-slug/.

Each feature folder must contain:

- SPEC.md - WHAT and WHY (user story, acceptance criteria, out of scope).
- PLAN.md - HOW (backend, frontend, test plan, risks).

Templates are defined in Task-List.md.

## Rule

No implementation starts until both SPEC.md and PLAN.md are approved and
recorded in Task-List.md.

## Naming

- specs/FEAT-001-auth/
- specs/FEAT-002-categories/
- specs/FEAT-004-search/
