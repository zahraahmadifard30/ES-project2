# Architecture Decision Records

This directory contains Architecture Decision Records (ADRs) for the project.

## Format

Each ADR follows the template defined in AGENTS.md section 6 and must include:
Status, Context, Options Considered, Decision, Consequences, and References.

## Naming

NNNN-short-kebab-title.md (e.g., 0001-use-vue-fastapi-tdd.md).

## Rules

- ADRs are immutable once Accepted.
- To change a decision, write a new ADR and mark the old one
  "Superseded by ADR-XXXX".
- Every non-trivial architectural decision requires an ADR before implementation.
